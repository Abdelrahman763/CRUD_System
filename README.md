# 🛒 CRUD System (Products Management)

A simple **CRUD (Create, Read, Update, Delete)** system built with **HTML, CSS, JavaScript, and Bootstrap**.  
The system allows users to manage products by adding, viewing, searching, and deleting items.

## 🚀 Features
- ➕ Add new products with:
  - Product Name  
  - Category  
  - Price  
  - Description  
- 📋 Display all products in a responsive table.  
- 🔍 Search for products by name or category.  
- ❌ Delete any product from the list.  
- 🎨 Built with **Bootstrap** for clean and responsive UI.

## 🛠️ Technologies Used
- HTML  
- CSS  
- JavaScript  
- Bootstrap  

## 🎯 Purpose
This project was created to practice:
- CRUD operations with JavaScript  
- DOM manipulation  
- Using Bootstrap for styling and layout  

## 📌 Future Improvements
- Add **Edit/Update** functionality for products.  
- Save data to **localStorage** so it persists after refresh.  
- Enhance UI with better design and animations.
